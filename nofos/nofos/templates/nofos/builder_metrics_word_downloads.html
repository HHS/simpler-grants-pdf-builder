These metrics count Word (.docx) download attempts from the NOFO export page, the readability metrics panel and the Readability Checker. A download counts as successful when NOFO Builder returns a Word document. Downloads that fail in the browser after that are not counted.

About these metrics

Figures cover currently retained attempts, not lifetime usage. Each attempt records its source, outcome, HTTP status, duration, whether the person was signed in, their OpDiv group at the time and, for Builder downloads, the NOFO. No document text, readability values, filenames or user IDs are stored. Requests rejected before the download starts (sign-in, permission and CSRF checks) are not counted.

Bloomworks and staging accounts are excluded, as on Usage & quality metrics. Every Builder download requires sign-in, so the signed-in filter applies only to the Readability Checker. An OpDiv filter keeps only signed-in downloads by that OpDiv’s users, so public Checker downloads appear only under All OpDivs.

Chart windows are the last 30 days and 12 weeks. Missing observations show “No data,” not zero: recording may have been off or retention may have removed records. The current day and week are in progress. Weeks start Monday; dates use the application time zone.
