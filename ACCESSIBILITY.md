# Accessibility

NOFO Builder produces NOFOs that the public uses to apply for federal funding.
Published PDFs and the Builder web app must meet
[Section 508](https://www.section508.gov/), which incorporates WCAG 2.0 Level AA.
Our goal is WCAG 2.2 Level AA where practical.

Read the repository's [accessibility guidance](documentation/ACCESSIBILITY.md)
for what Builder does, how output is checked, known gaps and how to report a
problem.

- **Published NOFO:** contact the agency contact listed in the NOFO.
- **NOFO Builder or this repository:** open a
  [bug report](.github/ISSUE_TEMPLATE/bug_report.md) and ask for the `A11y` label.
  Don't attach documents that aren't cleared for a public repository.
