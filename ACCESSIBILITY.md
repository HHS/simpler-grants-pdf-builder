# Accessibility

NOFO Builder helps agencies publish Notices of Funding Opportunity (NOFOs).
See the [accessibility guide](documentation/ACCESSIBILITY.md) for the standards
that apply, what to check before publishing, and known barriers.

- **Need an accessible copy of a published notice?** Ask the agency contact
  listed in the notice. If you need more help, see the
  [HHS accessibility contacts](https://www.hhs.gov/accessibility/hhs-digital-accessibility-statement/index.html).
- **Found a problem with NOFO Builder or this repository?**
  [Open a GitHub issue](https://github.com/HHS/simpler-grants-pdf-builder/issues/new/choose)
  and ask the team to add the `A11y` label. Include only information approved for
  public sharing.
