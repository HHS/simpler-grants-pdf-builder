# Five readability metrics

Captured September 15, 2026, in Chrome using the actual Django component,
application styles, JavaScript, and standard grid-container width. Values are
synthetic. These isolated previews are not production screenshots.

- Desktop, 1440px: five columns; labels and targets remain 16px and wrap.
- Tablet, 768px: two columns (2–2–1).
- Mobile, 390px: one column.
- Reflow, 320px: one column, representing the CSS viewport width of a
  1280px browser at 400% zoom (not an actual browser-zoom capture).

Checked for document horizontal overflow at all four widths: none.
Verified Enter closes the accordion and Space reopens it. Verified a missing
paragraph component shows Unavailable without a target assessment.
This is targeted layout verification, not a complete accessibility audit.
