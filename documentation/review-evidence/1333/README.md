# Word Readability Checker scope evidence

Local Chrome, synthetic DOCX, candidate metrics package. The upload used the
signed-in checker, including its isolated analysis worker. No production data,
credentials, or private source text is in the captures.

- [Desktop report](word-scope-desktop.png)
- [390 px report](word-scope-mobile.png)

The report counted 2 excluded cover words, 2 excluded contents words, and
12 excluded instruction words. The instructions came from a one-cell table
and a verified instruction box. Copy metrics included the same counts. Chrome
print output contained the same labels and counts without the instruction text.
The narrow layout did not overflow horizontally. This does not establish
producer-wide Word parity or approve package publication.
