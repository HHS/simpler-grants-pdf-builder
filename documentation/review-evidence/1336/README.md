# Non-cover Basic information rendering

Evidence for [#1336](https://github.com/HHS/simpler-grants-pdf-builder/issues/1336).

An isolated local Builder instance imported a synthetic FY27 Word document with
**Basic information** at the start of Step 1 and another subsection of the same
name under Step 3 → Project summary. Both captures use the same imported
document, theme and Chromium viewport. The before captures use the templates
from `bdf93d40`. The after captures use the patched templates.

| Surface | Before | After |
| --- | --- | --- |
| Editor, Step 3 table | [Subsection missing](editor-before.jpg) | [Subsection, instructions and Edit action](editor-after.jpg) |
| HTML preview, Project summary | [Heading and instructions missing](preview-before.jpg) | [Heading and instructions restored](preview-after.jpg) |

Regression tests also import the legacy Word variant and inspect the real
HTML submitted by the PDF generation path, with the provider mocked. The tests
check that the Step 3 instructions appear once and that the Step 1 metadata is
not duplicated. No PDF was generated by the external provider.
