# Security and Responsible Disclosure Policy

## Report a vulnerability

Submit security vulnerabilities through the
[HHS responsible disclosure portal](https://hhs.responsibledisclosure.com).
Do not submit vulnerability details through public GitHub issues or pull requests,
or send vulnerability reports by email. Reports may be submitted anonymously.
HHS recognizes participating researchers through its acknowledgments program.

Before conducting security research, review the
[HHS Vulnerability Disclosure Policy](https://www.hhs.gov/vulnerability-disclosure-policy/index.html)
for covered systems, permitted research, reporting instructions and disclosure
timing. Refer to that policy for scope and authorization.

## Questions

For questions about the disclosure policy, contact
[HHS.Cybersecurity@hhs.gov](mailto:HHS.Cybersecurity@hhs.gov), as listed in the HHS
policy. Use the reporting portal above for vulnerability submissions.

This guidance follows the
[Simpler Grants security policy](https://github.com/HHS/simpler-grants-gov/blob/main/SECURITY.md),
with the policy-question contact checked against the current HHS disclosure
policy on October 26, 2026. The HHS policy is the authoritative source for its
scope, terms and contact information.
